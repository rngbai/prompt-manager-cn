# 提示词管理器：个人提示词库

一个纯粹的中文浏览器提示词管理插件：把常用提示词保存在浏览器本地，方便搜索、整理、复制和复用。

## 为什么做这个项目

以前我会把提示词收藏到笔记软件里，但查找、复制和使用总要在浏览器和笔记之间来回切换。最近看到卡兹克分享的提示词文章，评论区有人提到可以用浏览器插件管理提示词，我觉得这种方式非常方便。

于是我找了一个开源插件作为基础，但发现它没有中文版，而且包含了不少 AI 助手接入、网站权限和社区目录功能。对我来说，这些功能并不是第一版的重点，所以我把它改成了一个更纯粹的个人提示词收录工具。

## 当前功能

- 本地保存、编辑、删除和搜索提示词
- 标签管理与筛选
- 使用 `#变量名#` 保存可填写的动态提示词
- 点击提示词直接复制到剪贴板
- 导入和导出 JSON
- 首次打开侧栏时自动加入 12 条精选提示词
- 不依赖 AI 网站权限，不要求接入任何特定 AI 平台

## 安装

1. 下载本项目，或下载页面中的 ZIP 压缩包。
2. 打开 Chrome 的 `chrome://extensions/`，或 Edge 的 `edge://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择项目中的 `src` 文件夹。

## 使用

打开扩展侧栏后，可以直接看到提示词列表。点击“新建提示词”添加自己的模板；点击提示词整行或复制按钮即可复制内容。包含 `#变量名#` 的提示词会先让你填写变量，再复制最终内容。

文章《都Agent时代了，我还是想分享给你这12个我最常用的Prompt》的 Markdown 整理版位于 [`docs/article-12-common-prompts.md`](docs/article-12-common-prompts.md)，对应的 12 条内置提示词位于 [`src/data/articlePrompts.js`](src/data/articlePrompts.js)。

