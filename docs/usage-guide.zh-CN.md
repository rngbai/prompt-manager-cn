# 提示词管理器使用教程

这是一款只服务于个人提示词收录的浏览器插件。提示词默认保存在当前浏览器的本地存储中，不需要登录，也不会自动上传到服务器。

## 一、安装插件

这是开发者模式加载版本，安装步骤如下：

1. 下载项目代码，或者在 GitHub 页面下载 ZIP 压缩包并解压。
2. 打开 Chrome 的 `chrome://extensions/`，或 Edge 的 `edge://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择项目中的 `src` 文件夹。
6. 安装完成后，点击浏览器工具栏中的插件图标，打开提示词管理器。

插件代码更新后，在扩展管理页面点击“重新加载”，再重新打开提示词管理器即可。

## 二、第一次打开

第一次打开侧栏时，插件会自动加入文章中的 12 条精选提示词。它们使用固定 ID 保存，重复打开或重新加载插件不会重复添加。

这些提示词按用途分为几个默认分类，例如“问清问题”“学习”“解决问题”“决策”和“认识自己”。你可以直接点击它们试用，也可以编辑成自己的版本。

## 三、新建提示词

1. 点击顶部的“新建提示词”。
2. 填写“提示词标题”。标题建议写清使用场景，例如“周报整理”“代码审查”或“产品需求拆解”。
3. 在正文区域输入提示词。
4. 需要分类时，在分类下拉框中选择一个分类。
5. 如果已经在设置中启用标签，可以为提示词添加标签。
6. 点击“保存提示词”。

提示词保存后会出现在列表中，后续可以继续编辑、复制或删除。

## 四、使用变量提示词

如果同一个提示词每次只替换少量信息，可以使用 `#变量名#` 标记动态内容。

例如：

```text
请帮我分析这份#文档类型#，目标读者是#目标读者#，最后输出#输出格式#。
```

使用方法：

1. 保存包含 `#变量名#` 的提示词。
2. 点击提示词，插件会列出需要填写的变量。
3. 填写变量内容后点击“复制”。
4. 粘贴到任意 AI 对话框或其他文本输入框中。

变量只在本次复制时替换，原始提示词模板不会被改写。

## 五、搜索、分类和复制

### 搜索

在“搜索提示词”输入框中输入标题、正文或标签关键词，列表会即时筛选。

### 分类

- 点击分类名称，只查看该分类下的提示词。
- 点击“+ 分类”可以新建分类。
- 编辑提示词时可以把它放入指定分类。
- 删除分类时，分类中的提示词会保留并变为“未分类”。

### 复制

- 点击提示词内容区域，可以直接复制完整提示词。
- 点击提示词右侧的复制按钮，也可以复制提示词。
- 复制成功后，直接粘贴到 ChatGPT、Claude、Gemini、DeepSeek 或其他 AI 工具中即可。

这个版本的核心动作是“管理和复制”，不会主动把提示词注入某个特定 AI 网站。

## 六、编辑和删除

1. 在提示词右侧打开操作菜单。
2. 选择“编辑”修改标题、正文、分类或标签。
3. 点击“更新”保存修改。
4. 如果不再需要某条提示词，选择“删除”并确认。

删除提示词后无法在插件内撤销，建议定期导出备份。

## 七、标签管理

1. 打开底部的“设置”。
2. 在“偏好设置”中打开“启用标签”。
3. 返回提示词列表，在新建或编辑提示词时添加标签。
4. 再次进入设置，可以调整标签顺序，或从所有提示词中移除某个标签。

标签适合表示提示词的用途、来源或状态，例如“工作”“写作”“文章精选”“待整理”。

## 八、导出和导入备份

### 导出

1. 打开“设置”。
2. 在“提示词管理”区域点击“导出”。
3. 浏览器会下载一个类似 `opm-backup-2026-08-21.json` 的备份文件。

备份文件包含提示词、分类、标签顺序和相关偏好设置。建议在更换电脑、清理浏览器数据或大规模修改前先导出一次。

### 导入

1. 打开“设置”。
2. 点击“导入”。
3. 选择之前导出的 `.json` 文件。

导入采用合并方式：已有提示词会根据固定 ID 和更新时间处理，新提示词会补充进来，不会直接清空当前列表。导入前仍建议先导出当前版本，方便回退。

## 九、数据保存位置和注意事项

- 提示词默认保存在当前浏览器的本地存储中。
- 清除浏览器扩展数据、卸载插件或更换浏览器配置文件，可能导致本地提示词丢失。
- GitHub 仓库中的 12 条精选提示词是公开示例；你自己新建的提示词不会自动同步到 GitHub。
- 想在多台电脑之间使用时，请在一台设备导出 JSON，再在另一台设备导入。
