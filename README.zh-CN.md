# 提示词管理器（中文版）

这是基于 Open Prompt Manager 3.0.2 的中文界面版本。

## 当前版本

当前版本聚焦个人提示词收录：保存、编辑、排序、标签、变量、搜索、导入导出和复制到剪贴板，不依赖 AI 网站权限。

扩展打开侧栏时，会自动补充公众号文章《都Agent时代了，我还是想分享给你这12个我最常用的Prompt》中的 12 条精选提示词。它们使用固定 ID 去重，不会覆盖已有提示词。

提示词变量继续使用原项目格式，例如 `#角色#`、`#主题#`。原有提示词数据不会被翻译或修改。

## 在 Chrome / Edge 中加载

1. 打开 `chrome://extensions/` 或 `edge://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目中的 `src` 文件夹。
5. 安装后点击扩展图标，即可进入个人提示词库。

## 常用操作

- 在侧栏中点击“新建提示词”保存模板。
- 使用 `#变量名#` 创建可填写的动态变量。
- 点击提示词整行或复制按钮，将内容复制到剪贴板；含有 `#变量名#` 的提示词会先让你填写变量。
- 使用分类栏筛选提示词，点击“+ 分类”可以新建分类；编辑提示词时可以把它放入指定分类。
- 每个分类中的提示词会自动显示连续序号，例如 `1.`、`2.`、`3.`。
- 在设置页中管理标签、导入导出和网站权限。

文章 Markdown 整理版位于 `docs/article-12-common-prompts.md`，提示词数据位于 `src/data/articlePrompts.js`。

## 说明

这是本地加载版本，不是 Chrome 商店发布包。提示词默认保存在浏览器本地存储中。
